## Method and rules

Each frame is produced exactly as the web tool produces it: `discovery.discover` (live TAP), `visits.plan_frames` (visits, 30-day bins, cap of 24 exposures), `FrameBuilder.build` (byte-range reads, background subtraction, flag masking, reprojection onto `grid.target_wcs`, per-pixel median). Measurements are on that 59×59 frame (6.15″ pixels, MJy/sr, background-subtracted). r is the distance in pixels from the expected position.

- **no-data ≤3 px**: NaN pixels with r ≤ 3 (of 29).
- **peak**: maximum finite value with r ≤ 3. **σ**: 1.4826 × median absolute deviation of all finite pixels with r > 7 (frame noise).
- **visible**: fewer than 3 no-data pixels and peak ≥ 5σ.
- **saturated core**: at least 3 no-data pixels and the maximum finite value with r ≤ 10 is ≥ 5σ (a hole surrounded by bright signal; saturated cores are NaN in the archive images).
- **not detected**: anything else. The rule tests for flux near the expected position; it cannot tell the target from an unrelated source within 3 px (18″).
- **Aperture sum** (variable stars): sum over pixels with r ≤ 3 converted to mJy (MJy/sr × pixel solid angle), no aperture correction; σ is the 1.4826 × MAD scatter of the same aperture placed on a 7-px grid of empty-sky positions (r > 10) of the same frame. A frame with a no-data pixel in the aperture is "incomplete" (the sum would be a lower bound). Variability: max − min over complete frames divided by the combined σ of those two frames, "yes" if > 5.
- **Position fit** (moving targets, frames not "not detected"): `Moffat2D + Const2D` fitted with `LevMarLSQFitter` to finite pixels with r ≤ 7; rejected unless amplitude > 0, 0.5 < FWHM < 10 px and the centre lies within that radius. With a no-data core only the wings are fitted, which can bias the centre.
- **Motion test** (first to last frame with a fit): "follows the predicted motion" if |measured − predicted| < 0.5 |predicted|; "static" if |measured| < 0.5 |predicted| (a fixed source near the expected position, i.e. not the target); else "inconclusive".

## Astrometric inputs

Expected positions are computed for each frame's mean epoch (mean start time of the exposures used). Method: astropy `SkyCoord.apply_space_motion` (rigorous space motion, radial velocity taken as 0) from the reference epoch, then annual parallax Δα cosδ = π(X sinα − Y cosα), Δδ = π(X cosα sinδ + Y sinα sinδ − Z cosδ) with Earth's barycentric X, Y, Z (AU) from `get_body_barycentric('earth')`. SPHEREx's own offset from Earth's centre (low Earth orbit) changes this by < 0.05 mas and is ignored.
